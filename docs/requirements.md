# 需求文档 — History Clipboard

## 项目简介

一款 Windows 历史剪贴板管理软件。自动记录用户复制的内容，支持文字和图片。用户可以查看、搜索、置顶、删除历史记录，并重新粘贴到任何应用。

## 用户画像

Windows 日常用户，非技术背景。希望有一个轻量级的剪贴板增强工具，避免重复复制相同内容，方便找回之前复制过的东西。

## 功能需求

### FR-01：自动记录剪贴板内容
- 软件在后台运行时，自动监控系统剪贴板
- 检测到新内容时，存入历史记录
- 支持类型：文字、图片

### FR-02：去重处理
- 连续复制相同内容时，不创建重复记录
- 而是将该记录的时间戳更新为当前时间，使其出现在列表最前面

### FR-03：历史列表展示
- 以卡片形式展示所有历史记录
- 按时间从新到旧排列
- 文字卡片：显示文字预览（前 200 字符）
- 图片卡片：显示缩略图
- 每张卡片显示相对时间（如"2分钟前"、"1小时前"）

### FR-04：搜索功能
- 在历史记录中搜索文字内容
- 输入时实时过滤列表（防抖 200ms）
- 只搜索文字记录，图片不参与搜索

### FR-05：置顶功能
- 用户可以将任意记录置顶
- 置顶的记录显示在列表最上方的独立分区
- 置顶的记录不受自动清理影响
- 可以取消置顶

### FR-06：删除功能
- 单条删除：点击卡片上的删除按钮
- 删除图片记录时同时清理图片文件

### FR-07：重新粘贴
- 点击卡片上的"复制"按钮
- 文字：将文字写回系统剪贴板
- 图片：将图片写回系统剪贴板
- 操作完成后显示"已复制"提示
- 用户随后可用 Ctrl+V 粘贴到目标应用

### FR-08：保留天数设置
- 可选：1天、3天、5天
- 默认：3天
- 超过保留天数的记录自动删除
- 置顶的记录不受影响
- 自动清理在启动时执行一次，之后每小时执行一次

### FR-09：后台常驻
- 软件启动后最小化到系统托盘
- 系统托盘显示图标
- 双击托盘图标打开窗口
- 右键托盘图标显示菜单（显示窗口 / 退出）

### FR-10：全局快捷键
- 快捷键：Ctrl+Shift+V
- 功能：呼出/隐藏历史窗口
- 可在软件启动时注册

### FR-11：开机自启
- 软件安装后默认注册到 Windows 启动项
- 开机后自动在后台运行

### FR-12：数据持久化
- 所有历史记录保存在本地硬盘
- 电脑重启后数据不丢失

## 非功能需求

### NFR-01：性能
- 剪贴板检测延迟 < 500ms
- 列表虚拟滚动，支持 5000+ 条记录不卡顿
- 搜索响应 < 100ms

### NFR-02：UI 设计
- 简洁直观，减少学习成本
- 主色调：浅蓝色 (#29B6F6)
- 白色背景，卡片式布局
- 窗口默认大小约 400×600 像素

### NFR-03：隐私
- 所有数据存储在本地，不上传任何服务器
- 数据文件夹位于用户目录下的应用数据目录

### NFR-04：安装
- 提供单个 .exe 安装包
- 安装流程简单，标准 Next-Next-Finish
